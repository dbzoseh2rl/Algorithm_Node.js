1. 동기(Synchronous) 방식
- 정의:
동기 방식은 코드가 순차적으로 실행되며, 한 작업이 완료될 때까지 
다음 작업이 대기하는 방식입니다.

즉, 작업이 블로킹(Blocking) 방식으로 동작합니다.

- 특징:
1) 순차적 실행:
코드는 위에서 아래로 한 줄씩 실행됩니다.
한 작업이 끝나야 다음 작업이 시작됩니다.

2) 블로킹(Blocking):
시간이 오래 걸리는 작업(예: 파일 읽기, 네트워크 요청)이 실행되면, 
그 작업이 완료될 때까지 프로그램이 멈춥니다.

3) 간단한 구조:
코드가 직관적이고 이해하기 쉽습니다.
디버깅이 쉽고, 예측 가능한 흐름을 가집니다.

4) 성능 문제:
I/O 작업(파일 읽기, 네트워크 요청 등)이 많을 경우, 
프로그램의 전체 실행 시간이 길어질 수 있습니다.

# 코드 예시
const fs = require('fs');

// 동기적으로 파일 읽기
const data = fs.readFileSync('input.txt', 'utf8');
console.log(data); // 파일 내용 출력
console.log('파일 읽기 완료');

#설명
fs.readFileSync는 파일을 읽는 동안 프로그램이 멈춥니다.=
파일 읽기가 끝나면 console.log('파일 읽기 완료')가 실행됩니다.



2. 비동기(Asynchronous) 방식
- 정의:
비동기 방식은 작업이 완료될 때까지 기다리지 않고, 다음 작업을 바로 실행하는 방식입니다.

즉, 작업이 논블로킹(Non-blocking) 방식으로 동작합니다.

- 특징:
1) 병렬적 실행:
여러 작업이 동시에 실행될 수 있습니다.
시간이 오래 걸리는 작업을 백그라운드에서 처리하고, 그 동안 다른 작업을 수행할 수 있습니다.

2) 논블로킹(Non-blocking):
I/O 작업이 진행되는 동안 프로그램이 멈추지 않습니다.
작업이 완료되면 콜백 함수, 프로미스(Promise), 또는 async/await를 통해 결과를 처리합니다.

3) 복잡한 구조:
코드의 흐름이 직관적이지 않을 수 있습니다.

콜백 지옥(Callback Hell)이나 프로미스 체이닝(Promise Chaining)과 같은 
문제가 발생할 수 있습니다.

4) 높은 성능:
I/O 작업이 많을 경우, 동기 방식보다 훨씬 빠르게 처리할 수 있습니다.

# 코드 예시
const fs = require('fs');

// 비동기적으로 파일 읽기
fs.readFile('input.txt', 'utf8', (err, data) => {
    if (err) throw err;
    console.log(data); // 파일 내용 출력
});

console.log('파일 읽기 중...');

#설명
fs.readFile은 파일을 읽는 동안 프로그램이 멈추지 않습니다.
파일 읽기가 완료되면 콜백 함수가 실행되어 파일 내용을 출력합니다.
그동안 console.log('파일 읽기 중...')가 먼저 실행됩니다.


3. 비동기 처리 방법
1. 콜백(Callback):
비동기 작업이 완료되면 실행되는 함수입니다.

단점: 콜백 지옥(Callback Hell)이 발생할 수 있습니다.

javascript
Copy
fs.readFile('input.txt', 'utf8', (err, data) => {
    if (err) throw err;
    console.log(data);
});

2. 프로미스(Promise):
비동기 작업의 성공 또는 실패를 처리하는 객체입니다.

.then()과 .catch()를 사용하여 결과를 처리합니다.

javascript
Copy
const fs = require('fs').promises;

fs.readFile('input.txt', 'utf8')
    .then(data => console.log(data))
    .catch(err => console.error(err));
    
3. async/await:
프로미스를 기반으로 한 문법입니다.

동기 코드처럼 비동기 코드를 작성할 수 있습니다.

javascript
Copy
const fs = require('fs').promises;

async function readFile() {
    try {
        const data = await fs.readFile('input.txt', 'utf8');
        console.log(data);
    } catch (err) {
        console.error(err);
    }
}

readFile();
